📝 Notes

🔍 Search

• query: Search text (required)
• tag: Filter by tag (optional)
• limit: Max results 1-20 (default 5)
• deep_search: Also search chunks (default false)

• query: Search text (required)
• max_results: Max documents 1-50 (default 10)

📤 Upload

• tag: Optional category/tag for the file
• title: Optional title (if null, AI will generate one)

• content: Note text (required)
• title: Optional title
• tag: Optional category/tag

📊 Evaluation (RAGAS)

• max_samples: Max queries to evaluate 1-500 (default 100)
• sample_percentage_override: Override sample % 1-100 (optional)

• limit: Max results (default 10)

📋 Logs

• q: Search text (required, min 2 chars)
• user_id: Filter by user (optional)
• log_types: "activity,operation,error" (optional)
• start_date/end_date: ISO format (optional)
• limit: Max results 1-200 (default 50)

📈 Dashboard

• period: "last_hour", "last_24h", "last_7d", "last_30d" (default "last_24h")
• interval: "hour" or "day" (for activity endpoint only)
