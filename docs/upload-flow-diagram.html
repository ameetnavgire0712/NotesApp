📸 Screenshot Capture — Detailed Sub-Flow

1 Popup sends startCapture to content.js
2 Content.js shows selection overlay on page
3 User drags to select area
4 Content.js → background.js captureVisibleTab
5 Crop on <canvas> at device pixel ratio
6 Store PNG in chrome.storage.local
7 Popup reopens → shows preview → user picks tag
8 Upload as FormData to /upload/screenshot
② Data Preparation & API Call
A
📦 Package Data
Screenshot / File / Webpage: → FormData with file (Blob) + tag (string)
Quick Note: → JSON with { content, tag }
Webpage PDF: also adds source_url field
B
🔐 Auth & Route
Central apiRequest() method in popup.js:
• Adds X-API-Key header from chrome.storage.sync
• Routes /upload/* endpoints → Fly.io (notesapp-upload.fly.dev)
• For FormData, omits Content-Type (browser sets multipart boundary)
⬇
③ Server Processing (Fly.io: notesapp-upload.fly.dev)
1
🔑 Validate API Key
Verify X-API-Key → look up user_id from api_keys table in Supabase.
Returns 401 on invalid key (extension auto-logs out).
2
📥 Receive & Process Content
/upload/screenshot: Parse FormData → save PNG to blob storage
/upload/file: Parse FormData → extract text (PDF/DOCX/XLSX/images via OCR) → save file to blob storage
/upload/quick-note: Parse JSON body → use raw text content
3
✂️ Chunk & Generate Title
• Extract text content (OCR for images, parser for PDFs/DOCX)
• Generate a descriptive title using LLM or content summary
• Split content into semantic chunks for vector embedding
• Store markdown version of content
4
💾 Store in Supabase
Insert into notes table:
{ id, user_id, title, content_markdown, tag, blob_url, created_at }
Insert chunks into note_chunks table (if chunked)
5
🧠 Generate & Store Embeddings
• Generate vector embeddings for each chunk (768-dim, BGE model)
• Upsert vectors into Cloudflare Vectorize (notesapp-vectors index)
• Each vector has metadata: { note_id, user_id, chunk_index }
• This makes the document searchable via the RAG pipeline
⬇
④ Response & Post-Upload
R
✅ Success Response → Chrome Extension
Server returns { success: true, note_id, title }
Popup shows "Saved successfully!" toast notification
Extension sends cacheInvalidated message to background worker
