Key Components

Component Technology Purpose
API Server FastAPI + Uvicorn REST API endpoints, authentication, request handling
Database Supabase PostgreSQL + pgvector Notes storage, vector similarity search, full-text search
Embeddings BGE-base-en-v1.5 (768 dim) Convert text to semantic vectors
Reranker ms-marco-MiniLM-L-6-v2 Cross-encoder for precise relevance scoring
LLM Groq (Llama 3.3 70B) Query analysis, tool selection, answer synthesis
Storage Azure Blob Storage Document file storage with SAS URLs

6. Reranking

Cross-Encoder Reranking Pipeline

┌─────────────────────────────────────────────────────────────────────────────┐
│                        RERANKING PIPELINE                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  INPUT: 6 candidate documents from hybrid_search                            │
│  MODEL: cross-encoder/ms-marco-MiniLM-L-6-v2                               │
│                                                                              │
│  STEP 1: Text Preparation                                                   │
│  ┌─────────────────────────────────────────────────────────────────────┐    │
│  │ For each document:                                                   │    │
│  │   title_text = title × 2 (repeated for weight)                      │    │
│  │   content = first_200_words + " ... " + last_100_words              │    │
│  │   doc_text = title_text + content                                   │    │
│  └─────────────────────────────────────────────────────────────────────┘    │
│                                                                              │
│  STEP 2: Cross-Encoder Scoring                                              │
│  ┌─────────────────────────────────────────────────────────────────────┐    │
│  │ pairs = [(query, doc1_text), (query, doc2_text), ...]               │    │
│  │ scores = model.predict(pairs)                                        │    │
│  │                                                                      │    │
│  │ Results:                                                             │    │
│  │   Doc 1 (Job Openings): +1.04                                       │    │
│  │   Doc 2 (Resume PDF):   -0.41                                       │    │
│  │   Doc 3 (Resume DOCX):  -2.10                                       │    │
│  │   Doc 4 (Other):        -5.50  ✗ (gap too large)                   │    │
│  │   Doc 5 (Other):        -7.20  ✗ (gap too large)                   │    │
│  │   Doc 6 (Other):        -9.30  ✗ (below threshold)                 │    │
│  └─────────────────────────────────────────────────────────────────────┘    │
│                                                                              │
│  STEP 3: Filtering                                                          │
│  ┌─────────────────────────────────────────────────────────────────────┐    │
│  │ THRESHOLD: -8.0 (absolute minimum)                                   │    │
│  │ MAX_GAP: 5.0 (from top score)                                       │    │
│  │                                                                      │    │
│  │ Top score = 1.04 → Max allowed = 1.04 - 5.0 = -3.96                │    │
│  │ ✓ Doc 1: +1.04 (passes) | ✓ Doc 2: -0.41 | ✓ Doc 3: -2.10         │    │
